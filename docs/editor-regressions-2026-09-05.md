# Editor regression repair, 2026-09-05

## Findings and implementation

- **Workspace loading overlay:** `main.ts` had written the lifecycle directly without clearing `ui.loading`. A later inventory reconnect made that stale startup flag visible again. Main now uses the same lifecycle invariant as the reducer and releases the DOM boot gate before notifying subscribers. Optional inventory loading no longer gates the scene's initial world load.
- **Incomplete terrain/buildings:** a wholly failed chunk batch previously stopped the remaining independent batches. Streaming now continues and retries missing chunks. Nearby surface and building-height layers load before the next distance band. Construction object geometry is projected to the chunk that owns it instead of repeating the complete building in every chunk. A real stored chunk shrank from 9,602,837 to 1,593,556 compact JSON bytes before legacy-object cleanup.
- **Linebrush save/revert/leftovers:** the server now retires a parent's previous generated children in the same transaction that creates the replacement. Generation compare-and-swap and stable command receipts protect edits from delayed/lost HTTP responses. The controller reconciles a committed command before retrying, refreshes the authoritative parent before editing and closes settings after success. Old browser batches that lack the generation contract are rejected before mutation.
- **New Linebrush buildings:** an explicit new-draft action works without an existing selection. New geometry starts at the actual terrain hit rather than adding another block to a rounded height.
- **Linebrush panel responsiveness:** storey changes from the Linebrush settings panel now remain local until Generate, tool exit or building selection changes. The dedicated storey tool retains its direct commit behavior. Two immediate count changes followed by roof selection were verified without sending a command or locking the panel.
- **Storey selection and dragging:** facade edges are clipped before perspective division. Hit areas have a contrast outline and a wider pointer target. Dragging uses the clicked facade point, including perspective; overlapping edges resolve to the nearest facade. Selection still precedes opening building settings. Existing variable storey profiles are retained, with 3 m as the default for newly adopted LoD2 buildings.
- **Imported wall orientation:** point-in-triangle incorrectly rejected interior points. Correcting the sign test keeps wall thickness facing the footprint interior for either imported edge direction.
- **Terrain beneath generated buildings:** removal now restores a proven original terrain material, including its cut-surface status, only while the generated object still owns the cell. It never reconstructs terrain from a guess or revives old building materials. Manual excavation/replacement remains intact. The historical audit of 14 complete logs found no proven terrain holes requiring data repair.
- **Baumkataster:** the Geodata summary now prefers the approved file collection over an empty ingestion catalog placeholder. `kennzeich` was not a global tree identifier: 7,864 distinct values plus 1,589 missing values explained the incomplete 9,453-point index. The approved GeoPackage contains 434,765 distinct `gisid` values. Index v2 validates identities, preserves old tree IDs at their proven locations and atomically publishes the complete index.

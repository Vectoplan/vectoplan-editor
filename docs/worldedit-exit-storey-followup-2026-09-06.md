# WorldEdit exit and storey follow-up, 2026-09-06

The standard for new Linebrush buildings is now 3.0 m: three one-metre wall rows with a separate editable slab assembly at the storey boundary. Existing uniform 2.645 m Linebrush profiles migrate to that standard when the user confirms the building. Explicitly moved slabs, partial top floors, custom defaults and imported LoD2 eaves remain unchanged. The migration is not written merely by selecting a building.

`stopPolygonAreaInteraction` previously rebuilt the full building on every primary-button release, including releases of settings icons and redundant calls while putting the tool away. It now rebuilds only after an actual interaction. A clean exit releases the preview and its monitor. A pending generation retains the same preview geometry until replacement meshes arrive; putting the tool away only removes editing controls. Pending source-hiding and readiness scans share a 100 ms cadence instead of hiding source meshes on every frame. A preview's computed storey cells are reused for confirmation and appearance changes; changed footprints, segments, layout, heights and imported roof/protected-cell inputs invalidate that cache.

F8 now records `worldEdit.draftPresent`, `pendingGeneration` and `busy` separately from `active`, so an inactive tool waiting for replacement meshes is distinguishable from a completed edit. The older capture's geometry growth cannot establish a preview leak because it lacks this state and geometry ownership information.

Validation uses the real WorldEdit controller with an isolated copy of a Berlin four-storey building. Project writes are intercepted; CAD calculation requests remain real. The browser audit covers immediate confirmation closure, a no-op repeat confirmation, validation errors, delayed persistence, retryable failures, delayed CAD/reloads, uncertain commit recovery, the production CAD timeout and overlapping generation handoffs. The exit variant additionally verifies the 3 m migration, exact fallback-group identity during a pending exit, no editing controls after exit and cleared telemetry after handoff. Clean exit and completed handoff each produced zero whole-scene traversals over 350 ms. A pending exit produced eight traversals over 350 ms, within the two scans per 100 ms limit.

Height-profile, building geometry, program/default labels, LoD2 editing, ownership, roof-wall and edit-visual tests passed. F8 observability passed 6/6 tests; TypeScript passed. These regressions verify lifecycle and geometry semantics, not a measured end-to-end FPS improvement on the user's live project.
